# IPv6 Address Parser - WebAssembly Demo

This directory contains the WebAssembly build of ipv6-parse for use in web browsers.

## Files

- `index.html` - Interactive demo page
- `ipv6-parse.js` - WebAssembly module with JavaScript glue code (generated by build)

## Accessing the Demo

When deployed to GitHub Pages, the demo will be accessible at:
https://jrepp.github.io/ipv6-parse/

## Building

To regenerate these files:

```bash
# From the repository root
./build_wasm.sh
```

See [README_WASM.md](../README_WASM.md) for detailed build instructions.

## Features

The demo page allows you to:

- Parse IPv6 and IPv4 addresses
- View formatted output (RFC 5952 compliant)
- Inspect address components (hexadecimal)
- See parsed flags (port, CIDR mask, zone ID, IPv4 embedding)
- Test various address formats interactively

## Browser Compatibility

- Chrome 57+
- Firefox 52+
- Safari 11+
- Edge 16+
